          Aide

          En mode normal, seules les lectures (?96.1, K37.1, _SKH) et l'arrêt d'urgence passent. Le mode maintenance suspend la logique robot de l'ESP32 et donne la main au terminal ; il est refusé pendant un mouvement. Les commandes qui font bouger le moteur ou modifient sa configuration demandent une confirmation (sauf mode expert).
